# Nexus

Finance Process Platform.

## Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS
- shadcn/ui + Lucide icons
- ESLint

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment variables

Copy `.env.example` to `.env.local` and fill in real values. Never commit `.env.local` or any file containing secrets.
